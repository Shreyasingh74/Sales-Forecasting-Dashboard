 Sales Forecasting & Business Performance Dashboard


This project analyzes historical sales data and predicts future sales trends using Power BI.

Features :
- KPI Cards (Sales, Profit, Orders)
- Region-wise Sales Analysis
- Monthly Sales Trend
- 6-Month Forecasting
- Interactive Filters/Slicers

Tools Used :
- Power BI
- Google Sheets
- CSV Dataset

Dashboard Insights :
- Sales performance by region
- Future sales forecasting
- Profit analysis
- Interactive business dashboard
